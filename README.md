# Student Performance Analysis

## 1. Project Overview
This project analyzes student academic performance based on Gender and Grade.

## 2. Objectives
- Analyze male and female student distribution.
- Compare grades between male and female students.
- Identify the highest and lowest grade counts.
- Compare average marks by gender.
- Understand the relationship between attendance and marks.

## 3. Dataset Information
- Total Rows: 3,000
- Total Columns: 9 (after removing personal identifiers)
- Dataset: Student Analysis

## 4. Tools & Libraries
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## 5. Data Cleaning
- Checked missing values.
- Checked duplicate records.
- Checked data types.
- Removed unnecessary personal identifier columns.

## 6. Analysis
- Gender distribution
- Grade distribution
- Gender-wise grade comparison
- Average marks by gender
- Attendance vs Marks

## 7. Key Insights
The project compares academic performance across genders and identifies patterns in grade distribution, average marks, and attendance.

## 8. Conclusion
This project helps understand student performance through data analysis and visualization. It provides useful insights into grades, gender distribution, and attendance patterns.
